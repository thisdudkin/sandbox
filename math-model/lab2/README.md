# Лабораторная работа №2 — множество Жюлиа–Фату

Интерактивное браузерное приложение для построения согласованных изображений множества Мандельброта и множества Жюлиа–Фату. Параметр `c` выбирается щелчком на левой комплексной плоскости, после чего правая плоскость полностью пересчитывается.

Интерфейс использует зацикленный видеофон `spider-man.mp4`. Из-за правил автозапуска браузеров ролик стартует без звука; кнопка «Включить звук» включает дорожку на фиксированной тихой громкости 12%. Рядом расположено управление паузой. При выборе нового параметра `c` запускается короткая декоративная «паучья» анимация, а для пользователей с `prefers-reduced-motion` фоновое движение автоматически останавливается.

## Цель работы

Изучить рекуррентные отображения в комплексном пространстве, реализовать escape-time алгоритм и исследовать влияние параметра `c`, числа итераций, порога выхода и масштаба на структуру фрактала Жюлиа–Фату.

## Математическая модель

Комплексное число представлено парой `z = x + yi`. Его квадрат и сложение вычисляются без сторонних математических библиотек:

```text
(x + yi)² = (x² − y²) + 2xyi
(x + yi) + (a + bi) = (x + a) + (y + b)i
```

Для множества Мандельброта начальная точка всегда `z₀ = 0`, а координата пикселя задаёт параметр `c`:

```text
z₀ = 0
zₙ₊₁ = zₙ² + c
```

Для множества Жюлиа–Фату координата каждого пикселя задаёт `z₀`, а `c` берётся из точки, выбранной пользователем на множестве Мандельброта:

```text
z₀ = coordinate(pixel)
zₙ₊₁ = zₙ² + c_selected
```

На каждом шаге проверяется `Re(z)² + Im(z)² > R²`. Квадратный корень для проверки выхода не вычисляется. Если выхода нет за `I` шагов, пиксель становится чёрным. Для расходящейся орбиты цвет строится по сглаженному номеру итерации. Число итераций вводится вручную в безопасном диапазоне `10 ≤ I ≤ 5000`, а интерфейс порога выхода предлагает `R ∈ {10, 20, 30}`.

## Пиксели и комплексная плоскость

При границах `[minRe, maxRe] × [minIm, maxIm]`, размере Canvas `W × H` и экранной точке `(px, py)`:

```text
Re = minRe + px / W × (maxRe − minRe)
Im = maxIm − py / H × (maxIm − minIm)
```

Знак перед `py` меняется, потому что экранная ось Y направлена вниз, а мнимая ось — вверх. Начальные границы обеих осей равны `[-5; 5]`. Canvas квадратный, поэтому масштаб по осям одинаков. Физическое разрешение умножается на `devicePixelRatio`, а ввод переводится через CSS-размер — координаты остаются точными на HiDPI-экранах.

## Архитектура

- `src/math/complex.ts` — чистые операции над комплексными числами;
- `src/math/viewport.ts` — прямое и обратное преобразование координат, масштабирование и панорамирование;
- `src/math/fractal.ts` — escape-time алгоритм и непрерывная палитра;
- `src/state/app-state.ts` — типизированное состояние допустимых параметров;
- `src/worker/fractal.worker.ts` — оптимизированный попиксельный расчёт вне UI-потока, включая аналитические проверки внутренних областей Мандельброта;
- `src/render/fractal-renderer.ts` — жизненный цикл Worker и отмена устаревших задач;
- `src/ui/canvas-controller.ts` — Canvas, DPR, мышь, touch/pointer, индикаторы;
- `src/main.ts` — связывание состояния и интерфейса.

Каждое представление имеет собственный Worker. При новом запросе предыдущий Worker завершается, а его `jobId` становится устаревшим; старый кадр не может заменить новый. Во время жеста масштаба или перемещения интерфейс мгновенно трансформирует последний готовый кадр, а после короткой паузы уточняет его полноценным расчётом. Плотность вычислительного Canvas ограничена коэффициентом 1,5 DPR — это сохраняет резкость, не умножая незаметно объём работы на HiDPI-экранах. Выбор `c` пересчитывает только Жюлиа, а не обе карты.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес (обычно `http://localhost:5173`). Полная проверка проекта:

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

## Запуск через Docker

```bash
docker build -t julia-fatou-lab .
docker run --rm -p 8080:8080 julia-fatou-lab
```

Откройте `http://localhost:8080`; healthcheck доступен по `/healthz`. Build-этап использует официальный `node:22-alpine3.22`: Node 22 — LTS-линия, совместимая с Vite 7, а Alpine уменьшает контекст выполнения. Runtime основан на `nginxinc/nginx-unprivileged:1.28-alpine`, слушает непривилегированный порт 8080 и работает пользователем `nginx`. В финальный слой попадают только `dist` и конфигурация Nginx. Хешированные ресурсы Vite кешируются на год, HTML использует `no-cache`, а неизвестные пути получают SPA fallback.

## Управление

- Наведите курсор на Canvas, чтобы увидеть комплексные координаты, состояние орбиты и число итераций до выхода.
- Щёлкните по множеству Мандельброта, чтобы выбрать `c`; маркер показывает выбранную точку.
- Вращайте колесо над любым Canvas для масштабирования относительно курсора.
- Перетаскивайте Canvas мышью или указателем для перемещения области.
- Выберите `I` и `R` в верхней панели — оба изображения будут пересчитаны.
- «Сбросить масштаб» возвращает обе плоскости к `[-5; 5]`.
- «Сбросить всё» возвращает обе плоскости к начальному масштабу и восстанавливает `I = 100`, `R = 10`, `c = −0.745 + 0.113i`.

## Рекомендуемые значения c

| c | Наблюдаемая форма |
|---|---|
| `−0.745 + 0.113i` | Детализированный связный «дендрит» |
| `−0.8 + 0.156i` | Тонкая спиральная граница |
| `−0.4 + 0.6i` | Связная закрученная структура |
| `0.285 + 0.01i` | Асимметричные завитки |
| `0.285 + 0i` | Множество с выраженными нитями |
| `−0.70176 − 0.3842i` | Плотная спиральная структура |

Значения можно выбрать приближённо по координатам курсора на левой плоскости. Точки внутри множества Мандельброта обычно дают связные множества Жюлиа, а точки вне его — несвязную «пыль».

## Анализ результатов и выводы

Параметр `c` определяет глобальную динамику отображения. Малое перемещение около границы множества Мандельброта способно резко изменить топологию Жюлиа: связная фигура распадается на острова и затем на пыль. Это делает левую плоскость картой возможных режимов правой.

Увеличение `I` со 100 до 300 уточняет классификацию медленно расходящихся точек и добавляет детали на границе, но почти линейно увеличивает максимальное время расчёта. При малом `I` часть внешних точек ошибочно остаётся чёрной. Увеличение `R` откладывает фиксацию выхода: форма математической границы для достаточно большого `I` сохраняется, но номера выхода и сглаженные цвета меняются, а вычисление может занять больше времени. Значения 10–30 значительно больше классической гарантированной границы 2 и соответствуют условию задания.

Масштабирование не создаёт новых математических свойств, но показывает самоподобные детали границы. Каждый экранный пиксель покрывает меньший участок комплексной плоскости, поэтому пространственная точность возрастает. При глубоком увеличении становятся заметны ограничения чисел JavaScript `number` (IEEE 754) и требуется больше итераций. HiDPI повышает физическое число пикселей и резкость, одновременно увеличивая объём расчёта. Web Worker сохраняет отзывчивость интерфейса, однако вычислительная стоимость остаётся порядка `O(width × height × I)`.

Итог: реализованный эксперимент показывает связь пространства параметров Мандельброта с динамическими множествами Жюлиа–Фату и наглядно демонстрирует компромисс между точностью, детализацией и временем вычисления.
