Создай готовую к запуску лабораторную работу на Python: обучи многослойный персептрон распознавать рукописные цифры из
набора MNIST, используя TensorFlow без Keras.

Подготовь один самодостаточный исполняемый файл `mnist_mlp_tensorflow.py`. Код должен запускаться командой
`python mnist_mlp_tensorflow.py` после установки TensorFlow и не требовать ручного редактирования. Ответь на русском
языке.

Реализуй работу последовательно:

1. Загрузи оригинальный MNIST из публичного источника без Keras. Разрешены только стандартная библиотека Python для
   скачивания, распаковки и разбора исходных файлов IDX, а также TensorFlow для всех тензорных вычислений, модели и
   обучения. При недоступности данных выведи понятное сообщение об ошибке.
2. Выведи число примеров, формы тензоров, диапазоны меток и пиксельных значений для обучающей и тестовой выборок.
3. Нормализуй значения пикселей из [0, 255] в [0, 1], преобразуй каждое изображение 28×28 в вектор из 784 признаков и
   оставь метки целыми индексами классов 0–9.
4. Реализуй MLP вручную через `tf.Variable`: матрицы весов и векторы смещений, скрытый полносвязный слой с ReLU и
   выходной слой из 10 логитов. Используй разумное количество скрытых нейронов и прокомментируй выбранную архитектуру.
5. Явно реализуй прямой проход TensorFlow-операциями: `X @ W + b`, ReLU, затем выходные логиты. Для предсказания класса
   используй `argmax`; объясни связь логитов, softmax и выбранного класса.
6. Реализуй функцию потерь через `tf.nn.sparse_softmax_cross_entropy_with_logits`. Обучай модель мини-батчами с
   `tf.GradientTape`; самостоятельно применяй к переменным шаг градиентного спуска. Не используй готовый цикл обучения
   или высокоуровневый оптимизатор.
7. На каждой эпохе выводи средние training loss и training accuracy. После обучения рассчитай loss и accuracy на
   тестовой выборке.
8. Построй матрицу ошибок средствами TensorFlow и без scikit-learn рассчитай для каждого класса 0–9: precision, recall и
   F1-score. Также рассчитай overall accuracy и macro-average для precision, recall и F1. Защити вычисления от деления
   на ноль.
9. Выведи итоговую компактную таблицу метрик и несколько примеров с истинной меткой, предсказанной меткой и отметкой о
   верности классификации. Не выдумывай значения метрик: они должны быть получены при запуске программы.
10. В конце кода добавь краткие комментарии о ключевых частях реализации.

После блока с кодом добавь три коротких раздела: «Как запустить», «Объяснение для защиты» и «Проверка требований».

В «Объяснении для защиты» ясно и кратко объясни:

- прямой проход: входные признаки, линейное преобразование, ReLU, логиты, softmax и выбор класса;
- backpropagation: как loss сравнивает прогноз с истинной меткой, как `GradientTape` получает производные по весам и
  смещениям и как градиентный спуск уменьшает loss;
- метрики: accuracy — доля верных классификаций; precision = TP/(TP+FP); recall = TP/(TP+FN); F1 = 2×precision×recall/(
  precision+recall); macro-average — простое среднее метрик по десяти классам;
- почему для многоклассовой задачи полезно показывать метрики по каждому классу наряду с общей accuracy.
